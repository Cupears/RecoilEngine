I'm porting Beyond All Reason to Android through my fork of [Recoil Engine](https://github.com/beyond-all-reason/RecoilEngine). My goal is to play a full match on my phone.

I've tested a local match and touch movement on Android. The current build shows the terrain and supports camera controls. I'm working on bringing unit controls and match startup into the same app.
